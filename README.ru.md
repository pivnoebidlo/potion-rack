# Potion Rack

Стеллаж красок и журнал проектов для тех, кто красит миниатюры. [English](README.md)

> 0.7 — переписанная версия (Svelte 5, без базы данных и локального сервера).

## Возможности
- **Краски**: бренд, серия, артикул, цвет, тип (акрил, контраст, смывка, металлик, для аэрографа…), статус (в наличии,
  заканчивается, закончилась, заказана, хочу купить), число баночек, оценка, цена, магазин, дата покупки, заметка, фото.
- Сетка и список, сортировка (в том числе по цвету — стеллаж радугой), фильтр по статусу, цвету, бренду, типу и тексту.
- **Похожие цвета**: ближайшие краски стеллажа по CIEDE2000 — чем заменить ту, что закончилась.
- Выбор цвета, поле hex и пипетка, которая берёт цвет с любого места экрана (например, с фото баночки).
- Фото из файла, из буфера обмена (⌘V) или перетаскиванием на панель.
- Предупреждение о дубликате (тот же бренд и название).
- **Каталог: 11 440 красок 34 брендов** (Citadel, Vallejo, Army Painter, AK, Scale75, Reaper, P3, Tamiya, MIG…):
  поиск по названию, серии или артикулу, краска добавляется одним щелчком — в наличие или в «Хочу купить». В панели
  краски — похожие краски каталога, которых у вас нет. Данные: [miniature-paints](https://github.com/Arcturus5404/miniature-paints),
  Rick Fleuren (Miniature Painter Pro), MIT; пересборка — `npm run build-catalog`.
- **Проекты**: фигурки в группах (армия, коробка, игра), у каждой — статья в Markdown, картинки, данные (производитель,
  масштаб, материал, ссылка, даты, цена) и её краски.
  - Доска от «кучи позора» до полки: карточку перетаскивают в другую колонку, чтобы сменить статус.
  - Редактор: ⌘E — чтение или правка; `@` — упомянуть краску со стеллажа (она добавится к фигурке); картинки вставляют
    или перетаскивают прямо в текст; `![подпись|400](images/x.jpg)` задаёт ширину, как в Obsidian.
  - Краски, упомянутые **жирным**, при чтении получают точку своего цвета; у краски видно, в каких проектах она есть.
  - Содержание статьи, обложка; всё читается в любом редакторе Markdown.
- **Рецепты**: как красится поверхность — шаги от грунта до высветлений (база, смывка, слой, кромка, сухая кисть,
  лессировка…), в шаге краска или смесь в частях с примерным цветом и заметкой. Рецепт предупреждает, если краски нет на
  полке; у фигурки — её рецепты, у краски — рецепты, где она нужна.
- **Список покупок**: краски, которые заканчиваются, закончились или которые хочется купить, по магазинам или брендам,
  с рецептами, где они нужны; «Куплена» возвращает краску на полку, «Пришла» — заказанную; список копируется текстом.
- Темы: системная, тёмная, светлая, **нейтральная серая** (не искажает образцы), «верстак». Английский и русский.
- **Смешивание**: краски смешиваются как пигменты (Кубелка–Мунк, [spectral.js](https://github.com/rvanwijnen/spectral.js), MIT) —
  синяя с жёлтой дают зелёную; «Подобрать смесь» перебирает краски вашей полки поодиночке и по две для нужного цвета
  (hex, палитра или пипетка) и сохраняет лучший вариант рецептом.
- **Резервные копии**: снимки красок, рецептов и статей сами собой; полная копия в zip. **PDF** статьи.
- Проверка обновлений при запуске, загрузка и установка прямо из приложения.
- ⌘1–⌘5 — краски, проекты, рецепты, смешивание, список покупок; ⌘K — поиск по всему; ⌘N — новая краска или фигурка, ⌘F — поиск, ⌘, — настройки.

## Данные
Стеллаж — обычная папка (по умолчанию `Документы/Potion Rack`), её можно положить в iCloud или Dropbox как есть;
изменения со стороны приложение подхватывает на лету:

    rack.json                       краски и рецепты
    paints/<id>/*.jpg               фото красок
    projects/<группа>/<фигурка>/
      figure.md                     frontmatter (статус, производитель, краски…) + статья
      images/*.jpg

Импорт из 0.6 (краски, фото, фигурки со статьями и картинками):

    npm run import-legacy -- <путь к potion_rack.db> <папка стеллажа> [<папка фигурок 0.6>]

## Разработка

    npm install
    npm run dev        # приложение с перезагрузкой (данные в .dev/)
    npm test           # тесты ядра
    npm run typecheck
    npm run dist       # сборка для своей системы

Стек: Electron 44, electron-vite, Svelte 5, TypeScript, Lucide, Vitest.
